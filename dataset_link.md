# Dataset

**GTSRB - German Traffic Sign Recognition Benchmark** (secondary dataset)

- Source: Kaggle, https://www.kaggle.com/datasets/meowmeowmeowmeowmeow/gtsrb-german-traffic-sign
- License: CC0 1.0
- 39,209 training images in 43 classes (class folders `Train/0` ... `Train/42`)
- Images vary in size and lighting; all are resized to 32x32 RGB before training
- The dataset is not stored in this repository because of its size (about 600 MB).
  Download it from the link above, or run the first cells of `train.ipynb`.
